# PT Root UI Bold

Дизайн использует PT Root UI Bold; файл PT-Root-UI-Bold.woff2 получен 1 октября 2026.
Original foundry: https://www.paratype.com/fonts/pt/pt-root-ui
Distribution archive: https://github.com/font-archive/PT-Root-UI/blob/main/Bold/PT%20Root%20UI%20Bold_Web.zip
Лицензия из поставки: OFL.txt, SIL Open Font License 1.1. Файл не изменён.
Используется только Bold 700; текст интерфейса каталога использует Arial, чтобы браузер не имитировал отсутствующий Regular.
