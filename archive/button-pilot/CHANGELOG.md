# Changelog

## 0.1.0 — 2026-10-01, подготовлено к визуальной приёмке

- Настроены React + TypeScript + Vite, CSS Modules и Storybook.
- Добавлен текстовый Button: шесть оформлений, два размера, две темы, нативные атрибуты и ref.
- Перенесены исходные цвета состояний с mapping к Figma node ID; генерация CSS variables из JSON.
- Подключён локальный PT Root UI Bold; stories и пример композиции вне Storybook.
- Добавлены тесты поведения, клавиатуры, CSS-состояний и отчёты доступности.
- Известные ограничения: контраст отдельных исходных цветов, демонстрационная иконка,
  сокращённые данные локального MCP. Визуальная приёмка пользователем не выполнена.
