Дата: 1 октября 2026. Статус: реализован, технические проверки выполнены; визуальная приёмка ожидается.

## Выполнено

Контракт и решения ghost-orange / danger 40 / focus-visible приняты пользователем.
Реализация: src/components/Button/Button.tsx, Button.module.css; exports src/index.ts.
Общие токены: src/tokens/buttons.json → src/styles/tokens.css. Stories рядом с компонентом.
PT Root UI Bold загружается локально из src/assets/fonts/ с лицензией.

## Контраст

Axe проверяет enabled/disabled каталог обеих тем; отчёт сохраняет все обнаруженные ошибки.
Браузерный тест требует отсутствия других WCAG-ошибок, но не маскирует контраст под успешную полную приёмку.

| Тема и оформление | Цвет текста / фон | Контраст по axe | Состояние |
|---|---|---|---|
| Light primary, 32/40 | #f8f9fb / #ff5722 | 3:1 | Требует решения дизайнера |
| Light ghost-orange, 32/40 | #ff5722 / #f8f9fb | 3:1 | Требует решения дизайнера |
| Dark danger, 32/40 | #e7ecf3 / #f9474a | 2.93:1 | Требует решения дизайнера |

Итого: 4 элемента light, 2 dark в проверенной матрице. Hover/active требуют отдельной оценки контраста.
Цвета сохранены из Figma; исправления не были согласованы и не вносились.
Полные отчёты: artifacts/browser/a11y-light.json и a11y-dark.json.
