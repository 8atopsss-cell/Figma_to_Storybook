# Контракт кнопок — проект для приёмки

Дата: 1 октября 2026. Статус: контракт Button и предлагаемые решения расхождений приняты пользователем.
Источник: SD Enterprice / UI kit. Текущая итерация — только кнопки.

## Архитектура

React + TypeScript, CSS Modules, общий JSON токенов с генерацией CSS variables.
Vite и Storybook для React/Vite — основа из исходного плана.
Общие темы light/dark переключаются на контейнере; отдельные компоненты для тем не создаются.
Первый шаг реализации: текстовый Button. IconButton — следующий отдельный шаг.
Публичные экспорты доступны вне Storybook; стили и токены подключаются по документированному пути.

## Button

Основные источники: light `4391:92045`, dark `1900:44830`.

| Свойство | Предложение |
|---|---|
| variant | primary, secondary, tertiary, ghost, ghost-orange, danger; по умолчанию primary |
| size | 32 или 40; по умолчанию 32 |
| children | Текст кнопки |
| startIcon / endIcon | Необязательные React-элементы; декоративные иконки скрыты от скринридера |
| disabled | Нативный disabled; действие не вызывается |
| fullWidth | По умолчанию false; true растягивает кнопку по контейнеру |
| type | Нативный button/submit/reset; по умолчанию button |
| остальные атрибуты | Нативные атрибуты HTML button, включая onClick, aria-*, ref |

Семантика — `<button>`. Enter/Space и переход Tab используют нативное поведение браузера.
Hover, active и focus-visible реализуются CSS; публичного свойства state нет.
Loading и вариант ссылки в текущую реализацию не входят: подтверждённой спецификации нет.
Ширина по содержимому; 112 px в образце не считается обязательной шириной всех кнопок.
Длинный текст проверяется в узком контейнере; предлагаем перенос и минимальную высоту 32/40 вместо обрезания.
PT Root UI Bold 14 из исходных текстовых стилей. Веб-файлы шрифта ещё не получены.

## Предлагаемые решения расхождений

1. Light `14853:131178`, `14853:131167`: отнести к ghost-orange по колонке и цветам, сохранить точные исходные node ID в mapping.
2. Disabled danger 40: использовать высоту 40; в реестре отметить отличие от фактических 39 в исходнике обеих тем.
3. Для клавиатуры добавить focus-visible: двойное кольцо с промежутком 2 px, внешнее кольцо цветом акцента темы. Проверить видимость на фоне каждой темы. Это предлагаемое дополнение, не состояние, полученное из Figma.
4. Единичный dark interactive (`12688:40238`) отложить до отдельного контракта IconButton.
5. Не менять Figma для исправления имён или размеров: предлагаемые решения применяются к коду и документируются после приёмки.

## IconButton

Источники: light `4473:81300`, dark `2804:63710`.
Обязательное доступное имя через aria-label. Нативная кнопка; общие правила клавиатуры и disabled.
Точный API и область переносимых вариантов согласовать после Button: исходные матрицы неполные (light 19, dark 14), размеры 18/24 не представлены одинаково в темах.

## Проверки Button

- Stories: шесть оформлений, оба размера, обе темы, disabled, иконки, длинный текст, полная ширина.
- Реальные hover/active/focus в браузере; состояния не подменяются props.
- Взаимодействия: клик, Enter, Space, отсутствие вызовов disabled, Tab и видимый focus.
- Проверки доступности, типы, линтер, сборка Storybook.
- Сравнение с Figma при совпадающем тексте и размере; отсутствие веб-шрифта фиксируется как ограничение, не как успешное совпадение.
- Импорт вне Storybook и композиция нескольких кнопок до завершения текущего пилота.

## Ограничения исходных данных

Локальный MCP позволяет читать структуру и PNG, но в прочитанных ответах нет Auto Layout, радиусов, границ, видимости слоёв и связей с переменными. Их точное соответствие требует дополнительных данных; значения нельзя выдавать за прочитанные из Figma.
