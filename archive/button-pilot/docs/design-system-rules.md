# Правила реализации

Общие значения находятся в src/tokens/buttons.json; CSS генерируется командой npm run tokens.
Смысловые токены ссылаются на базовую палитру. Эти алиасы созданы в коде; наличие соответствующих связей в Figma не подтверждено локальным MCP.
CSS Modules используют переменные темы контейнера data-theme=light/dark.

Button использует нативный HTML button; hover/active/focus-visible не представлены публичными props.
32/40 — минимальная высота; длинный текст переносится, иконки сохраняют размер.
Slot иконки 16 px, вложенный SVG 18 px: это намеренное соответствие прочитанному узлу `4391:92047` (wrapper 16) и `I4391:92047;1900:44734` (icon 18, координаты -1/-1). Экспортируемый ресурс ещё требуется проверить визуально.
Новые зависимости, темы, loading и ссылочная семантика требуют обоснования и контракта.

Источник цветов текущей реализации — fills компонента и Label. Размеры и отступы первоначально восстановлены из координат слоёв; радиус 0, границы 1 px, uppercase и letter-spacing .5 px были выбраны как визуальная реконструкция, поскольку первая версия MCP не возвращала точные свойства. Это описание существующих неподтверждённых значений, а не допустимый способ дальнейшего переноса. Аудит обновлений подтвердил исходный радиус 2 px и letter-spacing 1 px; эти расхождения в реализации пока сохраняются. Текущие возможности и ошибки MCP перечислены в docs/mcp-verification-2026-10-01.md.
Focus-visible и нормализация disabled danger до 40 приняты отдельно.
При дальнейшем переносе соблюдать раздел «Полнота данных Figma» в AGENTS.md. Недостающий параметр получать из другого структурированного источника или отдельно согласовывать с пользователем до реализации. Документирование догадки само по себе не разрешает её использование.
Визуальная приёмка дополняет проверку исходных параметров. Различия и существенные неизвестные значения должны быть явно перечислены и разрешены пользователем.
