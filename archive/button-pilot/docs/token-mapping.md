# Токены Button

Канонический источник: src/tokens/buttons.json. Полная таблица соответствия: поле sourceMap (тема, токен, node ID, поле, цвет, исходное имя варианта).
Токены button-{variant}-{state}-background/text ссылаются на color-{HEX}. Темы выбираются на контейнере.
Цвета enabled/hover/active/disabled прочитаны для размера 32 в обеих темах; общая модель размеров использует ту же палитру.
Шрифт button: PT Root UI Bold 14; source text style S:3ebbf30b45f23ef4e409755abd1722e125971514,.
Border, radius и точные свойства типографики частично реконструированы; исходные алиасы переменных недоступны.
Focus accent — выбранные цвета accent существующих тем для принятого дополнительного состояния.

Генерация: npm run tokens. Неизвестный alias приводит к ошибке. Сгенерированный src/styles/tokens.css вручную не редактируется.
