## Общие ресурсы и ограничения

- Прочитаны 184 локальных цветовых стиля и 12 текстовых стилей.
- В цветовых стилях представлены light и dark; темы не придуманы агентом.
- Текстовые стили используют PT Root UI, Regular/Medium/Bold. Для Button подключён локальный веб-шрифт Bold с лицензией; Regular/Medium пока не нужны.
- Раздел визуальной таблицы токенов: `9087:18598`.
- Рабочий сервер: `figma_codex_local`; отдельный `figma_bridge` при проверке не имел подключённых файлов.
- Первая версия `get_node_tree` возвращала сокращённые данные. После обновления 1 октября повторная проверка подтвердила properties с радиусами, Auto Layout, границами, видимостью, opacity, типографикой и style ID; textSegments и warnings также возвращаются. Матрица проверок: docs/mcp-verification-2026-10-01.md.
- Повторное обновление `figma_codex_local` добавило `get_variables`: получены 13 переменных и 4 коллекции, проверены пагинация, фильтр коллекции и связь радиусов dark Button с `corner radius/s_corner` (2 px). Схема dark set и `variantProperties` доступны для всех 49 вариантов. Light set при depth 0 возвращает предупреждение об отсутствии схемы; чтение его вариантов и прямое чтение/экспорт вложенных `I…` узлов завершаются `FIGMA_API_ERROR`. Точные запросы и границы проверки: docs/mcp-verification-2026-10-01.md.
- PNG Button light и dark получены; фон за прозрачными областями не считается цветом компонента.
- fileKey и идентификатор версии источник через overview не предоставил; URL файла пока не получен. Ссылки на узлы не выдумываем.

## Расхождения, требующие решения до реализации

1. Ghost → ghost-orange для `14853:131178`, `14853:131167`: соответствие принято пользователем, сохранены исходные ID.
2. Danger disabled 40: нормализация высоты 39 → 40 принята пользователем и проверена в браузере.
3. Focus-visible принят пользователем и реализован; клавиатура и видимость проверены автоматизированным браузером. Ручная приёмка ещё не выполнена.
4. Dark interactive (`12688:40238`) отложен по принятому контракту.
5. IconButton: матрицы тем и состояний отличаются. Недостающие варианты не следует автоматически придумывать.
6. Вопросы Input и Card отложены вместе с компонентами.
