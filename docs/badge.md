# Badge

Браузерная сверка: для исходной строки 1,9k сохраняется подтверждённая ширина текстового слоя 20 px как min-width. Метрика глифов браузера уже этой области; без неё счётчик получался 26.77 px вместо исходных 28 px. При пользовательском тексте min-width исходной строки не применяется, ширина следует HUG. Значение 20 px генерируется из text node.width, не подобрано по скриншоту.

Актуальная структура Storybook: Docs / Playground / Light / Dark. Один Playground следует общей панели темы, показывает варианты её исходной схемы и хранит выбор отдельно для light/dark. Count/count и xs сохраняют исходные различия; отсутствующий light xs не добавляется. Отдельные DarkPlayground, Count, DarkCount и SourceMapping удалены из навигации.

Источник: SD Enterprice, UI kit 933:24166. Выделение 5 октября 2026: badge dark 7049:29219 (7 вариантов), badge light 8750:115974 (6 вариантов). Свежий get_node_tree depth 5, limit 20 сохранён полностью в source/figma/badge-export.json. Все дочерние узлы получены, предупреждений нет. Preview обеих тем прочитаны для сопоставления структуры; они не использованы для определения параметров.

API: Badge, theme light/dark, variant из Property 1 и атрибуты span. Defaults и Controls вариантов получены из componentPropertyDefinitions каждой темы. Имена сохранены дословно: dark count, light Count, status ofline. Light xs отсутствует и не добавлен; типы исключают неподтверждённые сочетания. Компонент статический; MCP не предоставил поведения клика, наведения, клавиатуры или анимации, эти параметры неизвестны и не реконструированы.

Красные индикаторы имеют исходные размеры 10 / 16 / 24 px; dark xs — 8 px. Сохраняется strokeAlign CENTER: SVG ellipse воспроизводит геометрию и половину обводки внутри/снаружи. Толщина medium различается: 2 px dark, 3 px light. Онлайн/офлайн — фон 10×10 px, cornerRadius 5 px, вложенная точка 6×6 px в координатах 2,2. Невидимые белые fills внешних компонентов не становятся белым фоном.

Счётчик: исходный текст 1,9k; PT Root UI Bold 700, 11/12 px, letterSpacing 0, ORIGINAL case. Auto Layout HORIZONTAL/HUG, padding 1 px сверху/снизу и 4 px слева/справа, cornerRadius 8 px, stroke 2 px OUTSIDE. Исходный размер с текстом 28×14 px; при изменении текста ширина следует HUG, dark minWidth 14 px сохранён. OpenType features, цвета, opacity и style IDs перенесены по точным полям.

Текстовый слой не связан с публичным TEXT-свойством Figma. text — явное дополнение React API из characters исходного слоя; Controls не выдают его за componentPropertyDefinition. Преобразование числа в k, округление, локализация и предел счётчика не заданы источником; text принимает строку без автоматического форматирования.

Для индикатора, несущего смысл, потребитель задаёт доступное описание (например, role=img / aria-label); декоративный индикатор можно скрыть aria-hidden. Встроенные SVG скрыты от accessibility tree. Счётчик отображает текст; live region автоматически не добавляется.

Генерация: source/figma/badge-export.json → scripts/generate-badge-tokens.mjs → src/tokens/badges.json и src/styles/badge-tokens.css через npm run tokens. Каждый record содержит полный source node с исходными полями и node ID. Node boundVariables пусты; сохранён свежий ответ get_variables с коллекциями/режимами, но связи переменных не придуманы. Style IDs сохранены; совпадение цвета не объявлено alias.

Ограничения: отдельные stroke*Weight сторон MCP не предоставил, используется uniform strokeWeight. Нет проверки сложных remote/multimode сценариев. Контраст исходных цветов не исправляется автоматически; прежний долг Button остаётся открытым. По указанию пользователя тесты, сборки и браузерные проверки не запускались. Визуальная приёмка ожидает пользователя.
