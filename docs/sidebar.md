Sidebar компонуется из готового MenuButton; badge внутри него — существующий Badge medium. MenuButton получил icon slot для исходных иконок и isSelected для текущего пункта. Стили кнопки, native hover/active, focus и оформление Badge переиспользуются. API Sidebar: theme, layout, selectedId / defaultSelectedId, badgeItemIds, onSelectItem и native aside props/ref. Начально выбран users; клик меняет внутренний выбор или уведомляет управляемого потребителя. Маршрутизацию задаёт потребитель. Compact сохраняет доступные подписи и title.

Размеры: expanded 322×942, compact 120×942; Navigation x=32, y=156, ширина 258/56, gap=4. Исходные меню содержат 10 dark и 9 light пунктов. По постоянному разрешению пользователя на симметрию вложенных элементов обе темы содержат 11 пунктов: в light добавлены servers/licensing, в dark — kkp. Новых layout/state вариантов нет. Порядок общий, высота меню derived=546; исходная геометрия и количество элементов сохранены в raw. Недостающие пункты берут icon/геометрию соответствующего layout другой темы, оформление — из MenuButton нужной темы. Источники, origin, themeAdapted и positionOrigin записаны в sidebars.json; дополнения derived/user-authorized.

Скрытые подписи compact местами устарели. Доступное имя берётся из видимой подписи expanded: сначала соответствие по уникальному mainComponent иконки, иначе по позиции внутри того же исходного меню. Оригинальный скрытый текст и оба node ID сохранены. Некоторые light compact MenuButton ссылаются на dark: реализация следует light теме, изменение отмечено themeAdapted. Исходные badge скрыты; Controls позволяет включить готовый Badge в любом пункте.

ProductName использует PF BeauSans Pro SemiBold Italic, локального файла шрифта нет. Название, логотип и divider сохранены точными векторными контурами оригинального SVG каждого layout; шрифт не подменяется. Derived backdrop маскирует исходную область Navigation, где отрисовываются живые MenuButton. Raw SVG не изменяются. Native SVG width=323/121 сохраняет выступающий на один пиксель divider; root width=322/120. Название дополнено доступным текстовым h2. Скрытый LicenseLabel не отображается.

Pipeline: sidebar-export.json → scripts/generate-sidebar-tokens.mjs → sidebars.json, sidebar-api.ts, sidebar-tokens.css и assets/sidebars через npm run tokens. Все SVG имеют source IDs и SHA-256. Background aliases основаны на явных свежих style IDs. VECTOR и mixed vector radii сохранены SVG; mixed strokeWeight у invisible strokes не заменяется придуманным значением. Variable bindings отсутствуют.
