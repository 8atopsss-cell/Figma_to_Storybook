# Понятный вывод изменений Figma

Панель «Figma: изменения» показывает нумерованные пункты с названием свойства, темой, вариантом, состоянием и размером. Цветовые изменения имеют образцы «Было / Стало», HEX и названия назначенных стилей. Ссылка «Слой в Figma» открывает исходный узел.

Связанные изменения заливки, ссылки на стиль и добавленной записи того же стиля объединяются. Изменения разных слоёв и существующих общих стилей остаются отдельными. Все технические пути и исходные значения сохраняются в раскрываемых деталях без обрезания.

Панель показывает только компонент выбранной истории; названия слоёв и варианты берутся из компактного индекса исходных экспортов `.storybook/figma-sync/source-context.json`. Реестр и индекс автоматически обновляются при старте/сборке Storybook и изменениях источников в dev-режиме. Значения до и после всегда берутся из текущего ответа сравнения; индекс не подменяет живой снимок. Неизвестный слой показывается с ID и явным отсутствием контекста. Общий workflow новых компонентов описан в `figma-sync-registration.md`; отдельный запуск генератора — `npm run figma:sync-registry`.

Превью изменённых вариантов строится из точных сохранённых снимков `implemented` и `observed` через защищённый GET `/sync/previews?componentId=button`. Индекс исторического экспорта не используется для реконструкции превью. API отдаёт только затронутые варианты, их актуальный контекст, геометрию и фактические SVG-ассеты. Клиент проверяет ревизию и snapshotId, отменяет старые запросы и не показывает превью другой версии. Чтение превью не обращается к редактору Figma и не меняет приёмку; свежее сравнение и OK сохраняют свои проверки источника.

Показаны две схемы «Было / Стало» в масштабе 2×, размеры варианта, линейки отступов и пунктир изменённых областей. Это реконструкция по параметрам; браузерная типографика и сложные эффекты могут отличаться от рендеринга Figma. SVG вставляется как изображение, без исполнения его разметки в DOM.

Матрица трансформации расшифровывается в X/Y, поворот, масштаб и наклон. Дубли координат x/y объединяются с соответствующей матрицей. Подписи показывают конкретный сдвиг и величину изменений геометрии, сохраняя ноль и отсутствующие значения отдельно.

Проверено: 11 целевых unit/UI-тестов панели, 124 теста bridge, TypeScript обеих частей, ESLint изменённых файлов, сборки bridge/transfer и Storybook. В живом браузере новый установленный API показал dark / primary / enable / 32px: фон `#ff7043` → `#73b743`, отступы 16 → 20 px, ширину 112 → 120 px и сдвиги иконки/текста на 4 px. Десять технических записей представлены шестью пунктами.

Работа при скрытой/свёрнутой Figma остаётся отдельным пунктом бэклога bridge. Визуальная приёмка пользователю не назначалась, цвет Button в коде не менялся.
