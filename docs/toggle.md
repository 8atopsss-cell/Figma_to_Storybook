# Toggle

Свежий живой источник: SD Enterprice, UI kit 933:24166, выделенный component set toggle 700:20924. Все восемь вариантов и полная схема Property 1 без предупреждений сохранены в source/figma/toggle-export.json. Default Figma — disable dark. npm run tokens формирует канонический src/tokens/toggles.json и toggle-tokens.css. Bindings узлов и paints пусты; переменные не придумываются. Ссылки на style ID и все native поля остаются в raw и canonical source.

React + TypeScript + CSS Modules. Нативный input type=checkbox, role=switch, ref/name/value/form/onChange. Обязательное доступное имя — aria-label или aria-labelledby. Space и мышь работают нативно; disabled исключён из Tab и FormData. variant — исходное значение Property 1; checked выводится из позиции кружка, unactive интерпретируется как disabled. Это интерпретация поведения, Figma задаёт визуальные состояния. Компонент управляемый: родитель обновляет variant в onChange. Playground делает это через Storybook args; справочные Light/Dark сохраняют исходное состояние для сверки.

Тема включена в variant, поскольку исходная схема объединяет тему и состояние. Восемь вариантов доступны напрямую через Controls. Нет light disabled off и light danger: такие комбинации не генерируются. По уточнению пользователя danger сохраняется отдельно от on/off: prop danger=true применяет исходный Enable danger dark к включённому dark Toggle. Выключенное состояние использует исходный disable dark. Playground запоминает danger при выключении Enable danger dark и возвращает красный вариант при повторном включении; Danger story задаёт danger=true сразу. Управляемый потребитель сохраняет prop danger при обновлении variant. Light и disabled-оформления сохраняют исходные значения.

Размер 32×24. Track 25×10, radius 43 px, y=7; браузер ограничивает эффективный радиус половиной высоты, raw 43 сохранён. Thumb — настоящая Figma ELLIPSE 14×14, y=5, CSS border-radius:50%. Track x=4 в обычном off и x=3 в остальных; thumb x=2 в обычном off, x=1 в dark disabled off, x=16 во включённых. Все значения сохранены независимо, без выравнивания исходных различий. Dark on track зелёный, light on thumb красный, dark danger thumb красный — исходные цвета не унифицируются.

Последнее уточнение пользователя заменяет предыдущую последовательность движения и цвета: взять анимацию https://uiverse.io/lenin55/fast-chicken-43. Проверен исходник официального зеркала https://github.com/uiverse-io/galaxy/blob/main/Toggle-switches/lenin55_fast-chicken-43.html, git blob 78b812493da826aad2b787ee01526bdb3087fd59. Параметры и атрибуция: source/animation/toggle-uiverse.json. Автор lenin55, MIT. В исходнике transform и background-color переходят одновременно за 0.2s; easing не задан явно, значит CSS ease (cubic-bezier(0.25, 0.1, 0.25, 1)), задержка 0. Наши track и thumb плавно меняют исходный цвет одновременно с перемещением thumb за 200 ms ease в обе стороны. Прежнее ожидание Animation.finished удалено. При быстром развороте CSS разворачивает текущее движение и цвет; при reduced motion все переходы выключены. Размеры, координаты, цвета Figma, danger, Controls и native семантика сохранены. Тени, ripple и hover/active-оформление примера не переносятся. У track нет смены opacity, поэтому достаточно background-color transition. Focus-visible — прежнее техническое кольцо 2 px с offset 2 px. Визуальную приёмку назначает пользователь; контраст исходных цветов не меняется автоматически.

Проверки: 25 unit-тестов и полный браузерный прогон 28/28; typecheck, lint, Vite build и Storybook build проходят. Все восемь вариантов сверены по width/height, координатам, цветам, radius и native checked/disabled. Проверены keyboard/Space, focus-visible, Controls, disabled, danger, движение (200 ms ease), одновременная интерполяция цвета и позиции в dark/light/danger, разворот и reduced motion. В тестах переходы временно растянуты до 10 s и приостановлены посередине: и положение, и меняющийся фон имеют промежуточные значения; после завершения исходные значения совпадают.
