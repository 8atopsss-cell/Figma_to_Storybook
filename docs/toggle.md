Полные свойства и четыре используемых цветовых стиля сохранены в source/figma/toggle-enable-update.json. Enable dark: track dark_layer_03 #3E4A5C, thumb dark_status_success #73B743. Enable light: track light_layer_03 #DADDE4, thumb light_status_success #5FA339. Светлый Enable остаётся derived: геометрия из актуального dark Enable, соответствующая светлая палитра — решение пользователя перенести обновлённый вид в обе темы. Красные danger-состояния сохранены.

Проверки текущего изменения не запускались: пользователь запретил проверки в этой сессии. Ранее, до переименования и изменения Enable, прошли 31 unit-тест, typecheck, lint, обе сборки и 14 браузерных проверок Toggle. Эти результаты не подтверждают текущую версию. Визуальная приёмка ожидается.

Источник базовых восьми вариантов: SD Enterprice, UI kit 933:24166, set 700:20924; source/figma/toggle-export.json. Default Figma — disable dark. Добавлены два согласованных light-аналога: unactive off light и Enable light. Их реальные Figma node ID отсутствуют; происхождение записано в derivation. Палитра дополнений сохранена в source/figma/toggle-light-additions.json. Канонические токены src/tokens/toggles.json и CSS генерируются scripts/generate-toggle-tokens.mjs; generated CSS вручную не редактировать.

Одинаковые публичные имена и порядок обеих тем: disable, Enable, Enable danger, unactive on, unactive off, с суффиксом light/dark. Исходные enable light и unactive light отображаются как Enable danger light и unactive on light по решению пользователя. Оригинальная componentPropertyDefinitions не меняется; sourceVariant и variantAliases сохраняют происхождение имён. Дополненный список Controls хранится отдельно в variantsByTheme. Цветовые aliases используют явные Figma style ID; переменные Figma не придумываются.

Storybook: Docs / Playground / Light / Dark. Playground показывает один Toggle, следует общей панели темы; выбор lightVariant/darkVariant сохраняется отдельно. Controls: variant выбранной темы, общий danger, доступное имя. Danger доступен для обеих тем; прежний success удалён. Light/Dark — фиксированные интерактивные каталоги всех пяти состояний каждой темы. Каждый пример независимо сохраняет исходный зелёный или красный кружок после off/on.

React + TypeScript + CSS Modules. Native input type=checkbox, role=switch, ref/name/value/form/onChange. Доступное имя обязательно: aria-label или aria-labelledby. Space и мышь работают нативно; unactive соответствует disabled, исключается из Tab и FormData. Checked определяется исходной позицией кружка. Это интерпретация поведения, Figma задаёт визуальные состояния. Компонент управляемый: родитель обновляет variant в onChange. Prop danger=true применяет Enable danger соответствующей темы к обычному Enable; выключенное состояние — disable. Для возврата к красному кружку родитель сохраняет danger при off/on. Playground и каталоги делают это автоматически.

Размер 32×24. Track 25×10, radius 43 px, y=7; браузер ограничивает эффективный радиус половиной высоты, raw 43 сохранён. Thumb — Figma ELLIPSE 14×14, y=5, CSS border-radius:50%. Track x=4 в обычном off и x=3 в остальных; thumb x=2 в обычном off, x=1 в disabled off, x=16 во включённых. Все координаты сохранены независимо. Обычный Enable обеих тем имеет зелёный кружок и серую дорожку; Enable danger — красный кружок.
