# ResourceTag

Актуальная структура Storybook по запросу пользователя: Docs, Playground, Light, Dark. Playground показывает один тег с Controls и получает тему из общей панели Storybook; она одновременно меняет оформление тега и фон. Light/Dark фиксируют соответствующую тему, показывают все её варианты и доступные status online/offline рядом. Отдельные DarkPlayground, WithStatus, Offline, DarkOffline и SourceMapping удалены из навигации; происхождение данных сохранено в raw и токенах. Это заменяет прежнее описание отдельных историй ниже.

Актуальное решение пользователя 5 октября 2026: icon удалён из React API, Controls, историй и генерируемых CSS/records. Экспортируются 14 текстовых вариантов — по 7 каждой темы. Light icon не создавался. Исходная Figma-схема, raw и SVG сохранены для происхождения данных; exclusions явно фиксирует исключение dark icon 11088:25521. Controls используют отфильтрованные tokens.variants, не изменяя исходные componentPropertyDefinitions. Упоминания icon ниже относятся к исходной выгрузке до исключения.

Дополнение пользователя 5 октября 2026: добавлено состояние offline для видимого status. API status остаётся boolean для видимости; statusState='online' | 'offline' выбирает оформление, default online. В Controls добавлен statusState, истории Offline / DarkOffline. Это согласованное дополнение React API, не свойство исходного ResourceTag set. Источник offline: свежие Badge status ofline dark 14963:67837 (dot 14963:67838) / light 14963:72740 (dot 14963:72741), сохранены в source/figma/resource-tag-offline-export.json. Генератор переносит их геометрию, фон и серую точку, сохраняя исходную позицию badge внутри ResourceTag. Pattern/icon по-прежнему не получают status без исходной связи.

Источник: SD Enterprice, UI kit 933:24166. Выделение проверено 5 октября 2026: resource tag dark 2804:63984 (8 вариантов), resource tag light 4477:82225 (7 вариантов). Свежий ответ get_node_tree depth 4, limit 20 полностью сохранён в source/figma/resource-tag-export.json; все дочерние узлы получены. Предупреждения VECTOR закрыты тремя SVG фактических instance wrapper 11088:37462 / 11088:37465 / 11088:37467. Исходные цвета SVG сохранены.

API: ResourceTag, theme light/dark, variant с точным значением Property 1, text из Text#1600:4, status из status#14963:0 (dark) или status#14963:9 (light), атрибуты span. Defaults и Controls получены из componentPropertyDefinitions каждой темы. Значение delited сохранено как в источнике. Вариант icon существует только в dark; типы и отдельные Controls исключают неподтверждённую light-комбинацию.

Компонент — статический информационный span. MCP не предоставил спецификацию клика, keyboard action, hover, disabled-поведения или анимации: эти параметры неизвестны и не реконструированы. new disable / active disable перенесены как исходные оформления. Для icon доступное описание задаётся aria-label и role=img; декоративные SVG скрыты от accessibility tree. Badge декоративный; если status передаёт важную информацию, потребитель обязан дать ей текстовое описание.

Текстовые варианты фиксированы 40×18 px, radius 12 px; dark icon 56×19 px, radius 2 px. PT Root UI Bold 700, fontSize 12, lineHeight 14, letterSpacing 0.4000000059604645 px, ORIGINAL case. Геометрия текста, внутренние и внешние радиусы, fills/strokes/opacity и положения badge сохранены по точным узлам и полям. INSIDE stroke реализован inset shadow, без изменения размеров.

Auto Layout и padding сохранены в raw/source. Фактические размеры и координаты дочерних слоёв не всегда соответствуют простой CSS flex-раскладке: например, fixed 18 px height с вертикальным padding 4 px и lineHeight 14 px. Экспорт сохраняет фактическую фиксированную геометрию через абсолютное размещение, не выдаёт координаты за доказательство отступов. Расширение тега под длинный текст не согласовано: текст может переноситься/выходить за фиксированную область, как при HEIGHT textAutoResize. Его ширина не реконструируется.

Status включается только у пяти текстовых вариантов каждой темы со связью componentPropertyReferences.visible → status. Pattern не содержит badge, а скрытый badge dark icon не связан со status; эти варианты не получают выдуманного поведения. У исходных badge текстовых вариантов отображается фон 10×10 и зелёная точка 6×6 по соответствующим темам.

Node boundVariables всех выгруженных узлов пусты; сохранён свежий get_variables с 13 переменными, коллекциями и режимами, но радиусы/цвета не объявлены связанными с переменными. Явные fillStyleId, strokeStyleId и textStyleId сохранены в source каждого токена; совпадение цвета не превращено в alias. Все значения CSS генерируются из raw через scripts/generate-resource-tag-tokens.mjs → src/tokens/resource-tags.json / src/styles/resource-tag-tokens.css; generated CSS не редактируется вручную.

Ограничения: отдельные stroke*Weight сторон отсутствуют у MCP; текущий экспорт использует подтверждённый uniform strokeWeight. Corner smoothing равен 0, effects пусты, opacity 1. Сложные remote/multimode сценарии не проверены. Контраст исходных цветов не корректируется автоматически; прежний долг Button остаётся открытым.

По прежнему указанию пользователя тесты, сборки и браузерные проверки не запускались. Визуальная приёмка ожидает пользователя; полнота параметров не равна визуальной приёмке.
