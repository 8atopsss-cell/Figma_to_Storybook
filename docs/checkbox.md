# Checkbox

Проверка 6 октября 2026: текущая Figma переименовала labelled `Variant7` в `Indeterminate`; уже существующее публичное `indeterminate` отображает тот же неизменённый SVG. Проверены 153 узла, все 24 SVG и поведение обеих тем; исправления компонента не потребовались. Свежий снимок и ограничения: [checkbox-verification.md](checkbox-verification.md). Первоначальный raw и внутренние имена assets сохранены; визуальная приёмка ожидается.

Актуальная структура Storybook: Docs / Playground / Light / Dark. Playground использует общую панель темы, Controls checked/indeterminate/disabled/children/aria-label. Светлый и тёмный наборы включают варианты с подписью/без неё, skeleton и группы. Отдельные истории состояний, IconOnly, Skeleton, Groups и SourceMapping удалены из навигации.

Уточнение пользователя 3 октября 2026: empty ↔ selected ↔ indeterminate переключаются через плавное затухание трёх оригинальных SVG-слоёв. Длительность изменена с 300 на 200 ms, cubic-bezier(0.656, 0.003, 0.355, 1), easing как у Button; задержка старта 0 ms. Нативное состояние меняется сразу, визуальный переход длится 200 ms в обе стороны. При reduced motion переход отключён. Это дополнение заменяет прежнее отсутствие анимации Checkbox; skeleton остаётся статичным.

Уточнение пользователя 3 октября 2026: подпись не выделяется мышью для копирования (user-select: none); нативный клик по label продолжает переключать checkbox.

Поручение пользователя: перенести два выделенных фрейма SD Enterprice, UI kit 933:24166. Dark 1855:45494, light 4471:70612. Свежие деревья, схемы, исходные поля, bindings и modes: source/figma/checkbox-export.json. Канонические производные токены: src/tokens/checkboxes.json. npm run tokens генерирует CSS из raw, без чтения archive/button-pilot.

Set с подписью: dark 1855:45515, light 4471:70623, по семь вариантов. Set без подписи: dark 1085:37057, light 4471:70649, по пять вариантов. Группы: dark 1855:45690, light 4471:81021. Variant7 соответствует indeterminate: вложенный mainComponent прямо имеет вариант Indeterminate. Исходное имя сохраняется. Текстовые свойства Radio button item#1840:0 и Text#1858:0 сохранены в raw, публичный текст — children.

Нативный input type=checkbox: checked/defaultChecked, disabled, name/value, onChange и ref. Подпись через label; без текста обязателен aria-label либо aria-labelledby. Space переключает, disabled исключён из Tab и формы. indeterminate устанавливает DOM-свойство: браузер сбрасывает его при переключении. Управляемый потребитель должен обновить checked и indeterminate; Playground показывает этот сценарий. CheckboxGroup — fieldset/legend. Disabled fieldset работает нативно.

18×18, внутренний квадрат 16×16, радиус 2; точный контур и штрихи сохранены в 24 оригинальных SVG. Подпись PT Root UI Medium 500, 14/18, letterSpacing 0.30000001192092896 px, gap 8. SVG сохраняет свои paint без currentColor. Цвета текста получены из исходного узла, ссылки на style ID остаются в raw. Цвета не связываются с глобальными aliases по совпадению HEX. У проверенных узлов variable bindings пусты; новые связи не придумываются. Цвета иконки и текста могут различаться и сохранены независимо.

Skeleton — отдельный неинтерактивный status, исходная заглушка 121×14, radius 1, gap 8, без анимации. Hover использует отдельный исходный SVG и исходные совпадающие значения подписи; active не задан. Анимация смены состояния задана пользователем, её параметры описаны выше. Focus-visible: дополнительное кольцо 2 px, offset 2 px для клавиатуры; это техническое дополнение, не Figma-состояние.

Disabled indeterminate отсутствует в Figma. При такой комбинации нативная блокировка сохраняется, подпись получает исходный disabled-цвет, иконка остаётся исходной indeterminate; это композиция доступных состояний, без заявления о соответствии отсутствующему варианту. Длинные подписи показаны целиком одной строкой; это правило реализации, исходный образец имеет одну строку. Группы используют заголовок Bold 700, 14/18, letterSpacing 1 px, uppercase и интервалы 8 px.

SourceMapping показывает все 24 source ID. Каталоги Light/Dark, отдельные Selected/Indeterminate/Disabled/DisabledSelected/IconOnly/Skeleton, Groups и переключаемый Playground. Снимки дополняют сверку параметров; визуальную приёмку назначает пользователь. Исходные цвета не исправляются автоматически ради контраста.

Техническая погрешность ширины: исходная подпись 98 px, браузер с поставляемым Medium-шрифтом даёт 97.296875 px. Общая ширина 123.296875 вместо 124 px. Тест допускает менее 1 px при сохранении исходных типографических параметров; искусственный padding не добавляется. Это не назначает визуальную приёмку.

Проверки: 22 unit-теста и полный npm run test:browser — 16/16. Пять браузерных проверок Checkbox охватывают все 24 SVG, семь labelled-состояний обеих тем, типографику, native mixed/Space/disabled, геометрию групп и промежуточную opacity при переходах empty/selected/mixed во всех направлениях. Длительность 200 ms, easing, нулевая задержка и reduced motion проверены в браузере. npm run typecheck, lint, build и build-storybook проходят. Axe-каталоги Checkbox без нарушений; это не полная проверка контраста нетекстовых SVG. Полные отчёты artifacts/browser/a11y-checkbox-*.json. Прежний контрастный долг Button остаётся открытым.
